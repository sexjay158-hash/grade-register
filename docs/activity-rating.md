# 活动评级（2026-10-21 更新）

| 评级 | 折算比例 | 原始成绩为 90 时 |
| --- | ---: | ---: |
| 优 | 100% | 90 |
| 良 | 80% | 72 |
| 中 | 60% | 54 |
| 差 | 50% | 45 |
| 无 | 0% | 0 |

原始成绩保留，折算结果四舍五入到两位小数。“无”是已选择的 0% 评级；未选择评级不计算折算分，缺席、请假、未登记也不会自动变成零分。预览、活动记录、照片卡片和 Excel 导出使用同一份评级定义。

一次活动的同一小组共用评级，多张照片仍对应同一小组活动。年级负责人可在负责小组的草稿中设置评级；院负责人确认后，年级负责人不能再改评级或成绩，院负责人和管理员仍按原有权限操作。归档保护保持不变。

照片右上角可以写“优、良、中、差、无”中的一个。多个选项并列、结果不明确或不同照片评级冲突时不猜测、不覆盖，需人工核对。网页识别、本机 RapidOCR 和百度识别均已更新评级文字处理，但没有声称手写字符一定识别正确。

旧表“合格”“及格”兼容为“中”，保留 60%。历史数据库的 60% 档继续使用原来的内部标识 `pass`，不重写历史成绩与评级记录。
