# 活动列表删除

学院汇总的活动列表、小组内的活动列表，以及旧版平铺活动列表增加“删除活动”。确认框展示小组、活动序号、日期、已记录人数和照片数，明确告知会删除本次活动及成绩、等次和修改记录，不能将它误认为仅删除待办提醒。

年级负责人可删除自己负责小组的未确认草稿，空草稿及已录入成绩的草稿均可删除；详情页也增加相同入口。已确认活动仍仅由管理员或负责学院的院负责人删除。服务端重新校验账号、学院、年级负责范围、归档状态和活动版本，不依赖按钮是否显示判断权限。

复用原有删除事务：删除本次活动的成绩、等次和专属照片；仍由其他活动使用的共用照片保留，其他小组的成绩不动。该组后续活动序号前移，活动列表、待办、统计和导出随刷新更新。如果照片文件清理失败，页面明确提示，不伪装成全部清理完成。

列表中的版本随确认请求提交，期间有人编辑或确认活动则拒绝旧版本删除，刷新后重新核对。归档学院、归档学期仍不可写。

新代码集中在 `app/delete-activity-button.tsx` 和 `lib/activity-deletion.ts`，列表集成在 `app/group-activity-archives.tsx`、`app/workspace.tsx`，API 沿用 `app/api/event/[id]/route.ts`。关闭开关不能恢复已经删除的活动；恢复业务数据需使用对应的数据备份，源码快照不能代替数据备份。
