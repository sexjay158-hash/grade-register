# 我的待办

登录后默认进入“我的待办”，按当前学期和账号负责范围集中显示需要处理的事项。管理员可按学院筛选，院负责人查看本院，年级负责人查看负责小组；跨年级学生仍随小组管理，不另按学号拆开。

## 三类待办

- 照片需核对：待识别、需复核、有未匹配行或冲突提示的照片。点击“核对照片”进入照片列表，自动定位并高亮原图对应的卡片。
- 活动待完善：尚未录入成绩或出勤的草稿，以及录入后尚未选择评级的活动。点击后直接打开活动成绩表。
- 活动待确认：已经录入成绩或出勤并选择评级的草稿。年级负责人查看进度，院负责人和管理员核对后按原有流程确认。出现此提醒不代表系统已经替老师核对了照片与成绩。

同一活动只产生一条活动待办，避免缺成绩、缺评级时重复催办；照片提示与活动待办可以同时出现。完成后自动依据已保存数据更新，不增加“标记完成”的独立数据副本。多组关联照片在所有关联活动都确认后移出核对提醒。已经补选评级时，过时的“未能识别等次”提示不再生成照片待办；真实冲突仍需核对。未出现成绩的学生不会自动补零或记缺席。

支持类别筛选、按小组/学院/照片名称搜索、每页 20 条、手动刷新。保存活动或评级后立即更新；其他账号的修改沿用原有约 45–60 秒的自动刷新，也可手动刷新。网络错误时不显示“全部完成”，先提示数据可能过时。

## 权限与数据

待办由服务端已完成权限筛选的工作台数据生成，复用同一次查询，不增加数据库查询、独立轮询或外部消息推送。不新建业务表，不复制名单或成绩，不修改确认、归档及删除权限。

未归组照片仍遵守现有权限：管理员和原上传者可见，不能仅凭账号所属学院就把未匹配照片展示给其他负责人。管理员未匹配学院的照片在“全校”范围显示。归档学期和已归档学院的活动不生成可处理待办。
