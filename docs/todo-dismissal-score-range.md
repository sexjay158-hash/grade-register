# 待办提醒删除与成绩范围

## 待办删除

待办列表的“删除待办”只移除当前账号的这条提醒，不删除活动、成绩、评级或照片，也不替其他账号删除提醒。确认框明确说明操作范围。删除状态保存在数据库，刷新或重新登录后仍生效。

删除记录按学校、账号、学期、待办编号隔离。待办内容、关联活动版本或核对状态变化后，生成新的提醒版本，之前的删除不会掩盖新的问题。界面上方“恢复已删除待办”恢复当前账号、当前学期的提醒，不影响其他账号或学期。

服务端仅接受当前账号有权限查看且版本一致的待办；不能传入他人待办编号来修改他人提醒。归档学期不允许修改提醒。新增表为 `todo_dismissals`，迁移文件为 `drizzle/0006_todo_dismissals.sql`；运行时也使用幂等建表兼容本机更新。

## 成绩范围

数字成绩必须是 0～100，包含两端，允许小数。零分、缺席、请假和未录入继续分别处理。

- 活动成绩录入中，超范围输入显示提示；保存或确认前再次检查。
- 个人成绩录入显示提示并禁止保存异常值。
- 导出预览直接改分会提示异常，服务端拒绝单条或整组非法成绩。
- 照片识别保留负号；负分、超过 100、异常数字格式不会写入成绩，不裁剪成 0/100。异常行保留在待核对结果中，照片卡片提示 0～100 的范围限制。其他有效行可继续录入。

不会自动修改或清空历史成绩。如果历史数据存在超范围值，需核对原始资料后纠正；整组保存遇到异常旧值时也会提示修正，不能把超范围成绩重新保存。
